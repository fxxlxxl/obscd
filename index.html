Fortschrittsleiste

Ohne eigenes Startdatum gilt: Die letzten 90 Tage füllen die Leiste von 25 % bis 100 %, davor füllt sie sich langsam von 0 % (365 Tage vor dem Ziel) bis 25 %. Mit Startdatum füllt sie sich gleichmäßig vom Start bis zum Ziel und ist vor dem Start leer.

Der Füllstand gilt nur für die Vorschau hier. Im Stream füllt sich die Leiste nach der echten Zeit.

In OBS: Quellen, Plus, Browser, Link einfügen, Breite und Höhe wie empfohlen eintragen. Das Feld für eigenes CSS kannst du leer lassen, der Hintergrund ist automatisch durchsichtig.

Bei Bild-Upload steckt das (verkleinerte) Bild im Link. Für ein größeres Bild nimm die Bild-URL, zum Beispiel eine Datei aus deinem GitHub-Repository.
